# Age of Mythology: Retold fortification references: sources

Every file was opened and checked by eye. All are Age of Mythology: Retold (2024) captures: Retold HUD, Retold models, or Retold-only content. None come from the 2002 original, the Extended Edition, AoE2 or AoE4. One AoE4 image that turned up in a forum search (topic 270868) was thrown out. Files were re-encoded to JPG but not cropped.

Forum image URLs all start with `https://forums.ageofempires.com/uploads/default/original/3X/`. In the tables, `.../` stands for that prefix.
